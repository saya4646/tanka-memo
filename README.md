# 単価メモ

お店で商品を手に取ったときに、その値段が安いか高いかを判断するためのアプリです。
iPhoneのホーム画面に追加して使います。

- 値札の値段と内容量を入れると、100mL・100g・1個あたりの値段を出し、過去の記録と比べて「最安値更新・安め・ふつう・高め」を判定します
- 税抜の値札、割引（◯％引き・◯円引き）、まとめ売り（◯個パック）にも対応しています
- 「買った」「見ただけ」で記録でき、サイズ違いの比較や値段の移り変わりのグラフも見られます
- 記録ごとに値札や商品の写真を1枚残せます。撮ったあと、残したい部分を自由な長方形で切り取れます
- ドラッグストアの日用品（洗剤・柔軟剤・ティッシュ・シャンプーなど約80種）は商品名の候補が入っていて、タップで登録できます
- よく行くお店（ツルハ、ウエルシア、サンドラッグ、アオキ、カワチ、ヤマザワ、セイムス）を最初から登録しています
- 記録と写真はiPhoneの中にだけ保存されます（バックアップは設定から写真ごと保存できます）
